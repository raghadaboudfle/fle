C’EST ou IL EST ?

Comment choisir ?

En français, C’EST et IL EST peuvent parfois sembler très proches. Pourtant, ils ne remplissent pas toujours la même fonction. Pour bien choisir, il faut surtout comprendre ce que l’on veut exprimer.

▶ Observez d’abord

Regardez ces situations et observez l’emploi de C’EST et IL EST. Pourquoi utilise-t-on parfois l’un et parfois l’autre ?

1

C’EST pour identifier ou présenter

On utilise C’EST pour identifier ou présenter une personne ou une chose.

Avec un nom propre

— Qui est cet homme ? — C’est Paul.
— Qui est cette femme ? — C’est Marie.

Avec un déterminant + nom

C’est mon voisin.
C’est une amie.
C’est le directeur.
C’est un gâteau au chocolat.

Le déterminant peut être, par exemple, un article, un possessif ou un démonstratif : un, une, le, la, mon, ma, ton, ta, ce, cette…

2

IL EST pour reprendre et décrire un élément précis

On utilise IL EST lorsque le pronom « il » reprend une personne ou une chose précise, déjà identifiée ou clairement comprise dans le contexte.

— C’est Paul. — Il est très sympathique.
Ici, il reprend Paul.
Regarde ce gâteau. Il est magnifique.
Ici, il reprend ce gâteau.
J’ai goûté le gâteau. Il est délicieux.
Ici, il reprend le gâteau.

IL EST permet donc de reprendre un élément précis pour le décrire ou donner une information à son sujet.

3

Attention : C’EST + adjectif est aussi possible !

La formule « C’est + nom / Il est + adjectif » peut être utile pour débuter, mais elle ne suffit pas à expliquer tous les emplois.

On peut parfaitement dire :

C’est magnifique !
C’est génial !
C’est intéressant.
C’est difficile.

Dans cet emploi, ce a une valeur neutre : il peut renvoyer globalement à une situation, à un fait, à une idée, à une action ou à ce que l’on perçoit.

— J’ai fait ce gâteau moi-même. — C’est magnifique !

Ici, C’est magnifique ! peut porter sur le fait d’avoir fait le gâteau soi-même.

Comparez

C’est magnifique !

On porte un jugement global sur la situation, le fait ou ce que l’on perçoit.

Il est magnifique.

Il reprend précisément un nom masculin, par exemple le gâteau.

💡 Le contexte est essentiel. Il permet de comprendre ce que représentent ce et il.
4

Les professions : C’EST ou IL EST ?

Avec un déterminant

C’est un médecin.

C’est une professeure.

C’est un excellent cuisinier.

Profession sans déterminant

Il est médecin.

Il est professeur.

Il est cuisinier.

Pour indiquer simplement la profession, le nom de profession s’emploie généralement sans déterminant après IL EST ou ELLE EST.

5

Et les nationalités ?

Une nationalité peut fonctionner comme nom ou comme adjectif.

C’est un Français.

Français est ici un nom qui désigne une personne de nationalité française.

Il est français.

français est ici un adjectif qui indique sa nationalité.

✍️ Attention à la majuscule : un Français → nom ; il est français → adjectif.
6

Féminin et pluriel

Les mêmes principes s’appliquent au féminin et au pluriel.

Au féminin

C’EST ne change pas :

C’est Marie.
C’est ma voisine.
C’est une médecin.

Lorsque le nom repris est féminin, IL EST devient ELLE EST.

Marie ? Elle est sympathique.
Cette maison ? Elle est magnifique.
Ma voisine ? Elle est médecin.

Au pluriel

Devant un groupe nominal pluriel, on utilise dans la langue standard CE SONT.

Ce sont mes voisins.
Ce sont mes amis.

Lorsque le pronom reprend un nom pluriel, on utilise ILS SONT ou ELLES SONT.

Mes voisins ? Ils sont sympathiques.
Ces maisons ? Elles sont magnifiques.
C’EST → CE SONT
IL EST → ELLE EST / ILS SONT / ELLES SONT
⭐

LA RÈGLE D’OR

C’EST

→ pour identifier ou présenter

C’est Paul.

C’est mon voisin.

→ avec un déterminant + nom

C’est un gâteau au chocolat.

→ avec un adjectif, pour porter un jugement global sur une situation, un fait, une idée ou ce que l’on perçoit

C’est magnifique !

IL EST

→ pour reprendre une personne ou une chose précise et donner une information à son sujet

Paul ? Il est sympathique.

Le gâteau ? Il est délicieux.

→ avec une profession sans déterminant

Il est médecin.

💡 LE BON RÉFLEXE

Pour choisir, ne regardez pas seulement le mot qui suit : demandez-vous ce que vous voulez exprimer.

J’identifie ? → C’EST

Je reprends un élément précis pour le décrire ? → IL EST

Je commente globalement une situation, un fait ou une idée ? → C’EST

J’indique simplement une profession, sans déterminant ? → IL EST / ELLE EST

Au féminin et au pluriel, le principe reste le même :

Devant un groupe nominal pluriel : C’EST → CE SONT

IL EST → ELLE EST / ILS SONT / ELLES SONT
